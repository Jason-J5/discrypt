# Discrypt
Discrypt aims to bring pgp encryption to discord
* Discord is a very popular messaging application 
    * As it stands discord does not offer any e2e encryption
* Without E2E your messages, files of any sort can be accessible by the
company (Discord in this case) freely, and without notice.
* This problem can be solved very easily just by adding a layer of encryption
before the message is sent
    * This will be done by encrypting the users message with pgp encryption where the user has
access to their keys and all encryption/decryption is done client side
